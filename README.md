# RandomLaneAnalysis_OCR

**beatmania IIDX INFINITAS向けの非公式RANDOMレーン解析ツール（Windows用）**

OBS StudioからSpout経由でゲーム映像を受け取り、曲名・譜面・オプションを認識します。NORMAL譜面のノーツイベントを記録し、登録済みデータとRANDOM譜面を比較してレーン配置を解析・表示します。

**解析にはゲーム画面に表示された情報のみを使用します。ゲームプログラムの内部解析（リバースエンジニアリング）や、ゲーム内部のメモリ・データファイル等へのアクセスは行っていません。**

本ツールは公式製品ではなく、作者が個人で開発した非公式ツールです。

## 主な機能

- ゲーム画面から曲名・難易度・譜面オプションを認識
- 正規譜面のイベント情報をSQLiteデータベースへ記録
- 登録済み正規譜面とRANDOM譜面を照合し、レーン配置を解析
- 解析結果の直接オーバーレイ表示、OBSブラウザソース表示
- 解析履歴の表示とCSV出力
- 検出帯・表示位置などの設定GUI、登録曲名の編集

**注意：** 対象曲・譜面の正規譜面データが未登録の場合や、画面認識・同期に失敗した場合、RANDOM解析結果が表示されないことがあります。曲開始直後のCN・HCNなど、ノーツの取得が不正確になる場合があります。解析結果の正確性は保証されません。

## ダウンロードと導入

一般利用には、GitHubの **Releases** に掲載するWindows向けZIP（公開後）を使用してください。ZIPはフォルダごと展開し、`RandomLaneAnalysis_OCR.exe` を起動します。EXE版の利用にPythonのインストールは基本的に不要です。

**対応映像解像度：** ゲーム映像は1920×1080を前提に開発・検証しています。他の映像解像度での動作は未検証です。

**初回のテンプレート登録：** ゲーム画面由来のテンプレート画像はZIPに同梱しません。初回起動時にテンプレート画像が不足している場合、ランチャーから作成ウィザードを起動できます。利用者自身が用意した**1920×1080のスクリーンショット（必須）**から12種類のテンプレートを登録してください。

詳しい導入・初期設定・操作方法は **[導入・初期設定ガイド](README_RandomLaneAnalysis_OCR.md)** を参照してください。

### 必要なソフトウェア

- Windows（開発・運用環境はWindows 11）
- beatmania IIDX INFINITAS
- OBS Studio
- Spout 2 OBS Plugin（確認済み環境：1.12.0）
- Tesseract OCR（日本語 `jpn` と英語 `eng` の言語データが必要）

OBS側のSpout送信名は `Spout_OBS_Filter` に設定してください。インストール手順は上記ガイドを参照してください。
