# RandomLaneAnalysis_OCR — 導入・初期設定ガイド

更新日：2026-10-16
対象：Windows向け配布用EXE（PyInstaller onedir形式）

## 1. このアプリについて

本ツールは、beatmania IIDX INFINITASのゲーム画面に表示される情報を取得し、曲名・譜面・オプションの認識や、RANDOMのレーン配置解析・オーバーレイ表示を行うツールです。

**本ツールの解析は、ゲーム画面に表示された情報のみをもとに行っています。ゲームプログラムの内部解析（リバースエンジニアリング）や、ゲーム内部のメモリ・データファイル等へのアクセスは行っていません。**

**EXE版ではPythonのインストールやpipでのライブラリ導入は基本的に不要です。** 配布された `RandomLaneAnalysis_OCR` フォルダを丸ごと展開して使用してください。

**対応する映像解像度について：** 本ツールの画面認識・解析は、1920×1080のゲーム映像を前提として開発・検証しています。他の映像解像度での動作は未検証です。また、テンプレート作成ウィザードに読み込ませるスクリーンショットは**1920×1080が必須**です（異なるサイズの画像は読み込めません）。PCモニター自体の解像度を1920×1080に固定するという意味ではありません。

ゲーム画面由来のテンプレート画像は配布ZIPに同梱しません。利用者自身がゲーム画面のスクリーンショットを用意し、初回設定で登録してください。

## 2. 別途インストールするもの

| ソフト | 必要性 | 用途・備考 |
|---|---|---|
| Tesseract OCR | 必須 | OCR。**日本語 `jpn` と英語 `eng`** の言語データが必要 |
| OBS Studio | 現在のSpout映像入力構成では必要 | ゲーム映像の取得・Spout送信 |
| Spout 2 OBS Plugin | 現在のSpout映像入力構成では必要 | OBSからSpout映像を送信。**動作確認済み：1.12.0** |
| Python / pip | EXE版では不要 | Python版で実行する場合は別途必要 |

Windows向けに作成したEXEです。ほかのOSでの動作は対象外です。GPUドライバ等は各PCの環境に依存します。

### ダウンロード先

- OBS Studio（公式）：https://obsproject.com/
- Spout 2 OBS Plugin（開発元のReleases）：https://github.com/Off-World-Live/obs-spout2-plugin/releases
- Tesseract OCRのWindows導入案内：https://tesseract-ocr.github.io/tessdoc/Installation.html
- Tesseract OCRのWindows向けインストーラー（UB Mannheim）：https://github.com/UB-Mannheim/tesseract/wiki

**注意：** 外部ソフトは各配布元から入手してください。このアプリのZIPにOBS・Tesseractのインストーラーが含まれているわけではありません。

## 3. Tesseract OCRの導入

1. Windows用Tesseract OCRをインストールします。
2. インストール時に**日本語（jpn）と英語（eng）**の言語データを選択します。
3. 推奨インストール先：`C:\Program Files\Tesseract-OCR\`。
4. 標準のインストール先以外を使う場合は、`tesseract.exe` があるフォルダをWindowsの環境変数 `PATH` に追加します。
5. アプリを起動し、ランチャーに **「Tesseract OCR：正常（jpn / eng）」** と表示されることを確認します。

必要に応じて、PowerShellから次のコマンドで言語データを確認できます（標準のインストール先の場合）。

```powershell
& 'C:\Program Files\Tesseract-OCR\tesseract.exe' --list-langs
```

出力に `jpn` と `eng` が含まれていることを確認してください。ランチャーに「利用不可」と出る場合は、インストール先と言語データを確認し、「Tesseract 再チェック」を押してください。

## 4. OBS Studio / Spoutの導入と設定

1. OBS Studioをインストールします。
2. **Spout 2 OBS Plugin** をインストールします。現在の動作確認済み環境は **バージョン1.12.0** です。
3. OBSでINFINITASのゲーム映像を取得できるシーン／ソースを用意します。(ゲームキャプチャで「[bm2dx.exe]: beatmania IIDX INFINITAS」)
4. OBSのSpout送信機能を設定し、**送信側のSpout名(上記ゲームキャプチャのフィルタ→エフェクトフィルタのSpout Filterで設定)が `Spout_OBS_Filter`** になるようにします。
5. OBSでゲーム映像が表示され、Spout送信が有効な状態でアプリを起動します。

> **重要：** `Spout_OBS_Filter` は、このアプリで使用している接続名です。OBSのSpout出力名と一致させてください。OBS側で使うメニュー・フィルタの詳細は、シーン構成やプラグインの設定方式によって異なります。現時点では具体的なOBS画面操作の手順までは実機照合していません。

接続名はアプリの **「⚙ 設定」→ 5番目「Spout接続名」** に表示されます。読み取り専用の欄をドラッグ選択して `Ctrl+C`、または「コピー」ボタンでコピーできます。ここで接続名を変更することはできません。

## 5. アプリの配置と起動

配布されたZIPを展開し、**フォルダ内のファイルを削除・移動せず**に利用してください。

```text
RandomLaneAnalysis_OCR/
├─ RandomLaneAnalysis_OCR.exe
├─ _internal/
└─ （配布物に含まれるその他のファイル・フォルダ）
```

1. OBSを起動し、ゲーム画面の取得とSpout送信を準備します。
2. `RandomLaneAnalysis_OCR.exe` を起動します。
3. Tesseract OCRが「正常」であることを確認します。
4. テンプレート画像が不足している場合、起動時に「テンプレート初期設定」の案内が表示されます。利用者自身が用意した1920×1080のゲーム画面スクリーンショットからテンプレートを登録します（次節参照）。
5. 必要に応じて「⚙ 設定」から表示・検出帯・履歴などを調整します。
6. 「▶ スタート」で分析を開始します。
7. 使用後は「■ ストップ」で分析を停止してから終了してください。

## 6. テンプレート画像の初期設定

本ツールはゲーム画面由来のテンプレート画像を同梱していません。初回利用時は、**利用者自身がゲーム画面から撮影した1920×1080のスクリーンショット**を使用して登録してください。画像の切り抜きはランチャーの「テンプレート作成ウィザード」で行います。

### ウィザードの開き方

- 起動時にテンプレート画像の不足が検出されると「テンプレート初期設定」の確認画面が出ます。「はい」を選ぶとウィザードが開きます。
- 後から登録・修正する場合は、ランチャーの **「⚙ 設定」→「テンプレート作成ウィザード」** から開けます。
- 必要な画像がすべて登録されていない場合、ランチャーの「▶ スタート」を押しても分析は開始されず、不足しているファイル名が表示されます。

### 登録の手順

1. ウィザード上部で **プレーサイド（1P／2P）** と **スコアグラフ位置（左／右）** を選択します。切り抜き位置の初期値はこれらの選択に応じて変わります。
2. 画面に表示されるテンプレート名と撮影場面の説明を確認し、「スクリーンショットを開く (1920x1080)」で該当する画像を選びます。PNG、JPEG、BMP形式に対応します。**画像サイズが1920×1080でない場合は読み込みできません。**
3. 全体画像に示される切り抜き枠と、右側の「新規切り出し画像」プレビューを確認します。位置がずれていれば矢印ボタンで1ピクセルずつ調整できます。「位置リセット」で初期位置に戻せます。
4. 「この画像を登録」を押すと、`templates/` フォルダに該当画像が保存されます。左側の「登録済み画像」と見比べながら確認できます。
5. 「次へ」で次の項目に進み、**12種類すべて**を登録します。画面下部に登録済み数（`/ 12`）が表示されます。「前へ」で戻ることもできます。

### 登録する12種類

| テンプレート名 | 用意するゲーム画面 |
|---|---|
| `PLAYER_01_SIDE.png` | ゲーム起動後のプレーサイド選択画面 |
| `PLAYER_02_SIDE.png` | ゲーム起動後のプレーサイド選択画面 |
| `NO_ENTRY.png` | プレーサイド選択後のプレーヤーエントリー画面 |
| `OP_CURRENT_SCORE.png` | 選曲後、GET READY表示前のプレー開始前画面 |
| `SCRATCH.png` | 選曲後、GET READY表示前のプレー開始前画面 |
| `GET_READY.png` | プレー開始直前、GET READYが表示されている画面 |
| `Op.MIRROR.png` | MIRRORオプションを使用しているプレー画面 |
| `Op.RANDOM.png` | RANDOMオプションを使用しているプレー画面 |
| `Op.R-.png` | R-RANDOMオプションを使用しているプレー画面 |
| `Op.S-.png` | S-RANDOMオプションを使用しているプレー画面 |
| `Bridge_to_Result.png` | プレー終了後からリザルト画面の間に表示される、黒背景に青い輪の画面 |
| `Failed_to_Bridge.png` | プレー途中終了直後の赤背景画面 |

**補足：** 登録済み画像を上書きする場合は確認画面が表示され、元の画像は `template_wizard_backup/` にバックアップされます。スクリーンショットの内容や切り抜き位置が適切かは、プレビューを見て利用者自身で確認してください。なお、12種類のファイルが存在していても、画像の内容が正しいことまで自動検証するものではありません。

## 8. 使用方法
1. アプリを起動する
   - RandomLaneAnalysis_OCR.exe をダブルクリックしてランチャーを起動します。
   - 起動時にTesseract OCRの動作確認が自動実行されます。
   - 「Tesseract OCR：正常」と表示されたら、テンプレート画像の登録状況も確認してください。テンプレートが不足している場合は登録完了まで分析を開始できません。
2. OBS Studioを起動する
   - OBS Studioを起動し、beatmania IIDX INFINITASのゲーム映像が取得できていることを確認します。
   - ゲームキャプチャの対象は [bm2dx.exe]: beatmania IIDX INFINITAS です。
   - ゲームキャプチャの「フィルタ」→「エフェクトフィルタ」→「Spout Filter」で、Spout送信名が Spout_OBS_Filter になっていることを確認します。
   - OBSはアプリ使用中も起動したままにしてください。
3. 初回設定を確認する
   - ランチャーの「⚙ 設定」から、必要に応じて以下を調整します。
     - 検出帯設定：ゲーム画面上のノーツ検出位置を設定します。
     - 履歴オーバーレイ設定：履歴の表示位置や大きさなどを調整します。
     - RANDOM分析結果表示設定：分析結果の表示位置やON/OFFを設定します。
     - 曲名DB編集：登録済みの曲名・譜面データを確認・編集します。
     - テンプレート作成ウィザード：ゲーム画面のスクリーンショットからテンプレートを登録・更新します。
     - Spout接続名：OBS側に設定する接続名を確認・コピーできます。
   - 設定が完了している場合、毎回変更する必要はありません。
4. 分析を開始する
   - ランチャーの「▶ スタート」をクリックします。
   - 正常に起動すると、状態表示が「分析中」になります。
   - INFINITASを操作して、通常どおり選曲・プレーしてください。
5. 曲名・譜面の自動認識
   - ゲーム画面から曲名・難易度・譜面オプションを自動認識します。
   - 認識した曲名はランチャーの「分析情報」に表示されます。
   - 正規譜面のプレーでは、正規譜面のイベントデータを取得・登録します。
   - 登録済みの正規譜面データは、以降のRANDOM分析に利用されます。
6. RANDOM分析結果を確認する
   - RANDOMオプションでプレーすると、登録済みの正規譜面データと比較してレーン配置を解析します。
   - レーン配置が確定すると、RANDOM分析結果のオーバーレイおよびOBSブラウザソースの「web\iidx_random_overlay_keyboard.html」に表示されます。
   - ランチャーの「分析情報」からも結果を確認できます。
   - 正規譜面データが未登録の場合や、画面認識・同期に失敗した場合は、分析結果が表示されないことがあります。
7. 履歴を確認する
   - 分析履歴は履歴オーバーレイやOBSブラウザソースの「web\iidx_history_overlay_obs.html」で確認できます。
   - 履歴CSVの自動出力機能により、フォルダ「history_csv」にて記録された分析結果を後から確認することもできます。
   - 履歴の表示方法は「履歴オーバーレイ設定」から調整できます。
8. 分析を終了する
   - ランチャーの「■ ストップ」をクリックします。
   - 停止確認が表示された場合は、内容を確認して終了してください。
   - 分析処理が停止したことを確認してから、ランチャーを閉じてください。

**使用上の注意**
- 分析中はOBS StudioとSpout送信を停止しないでください。
- 1920×1080のゲーム映像を前提として開発・検証しています。他の解像度は未検証です。ゲーム画面のレイアウトやLIFTなどの設定を変更した場合も、検出帯やテンプレートの再確認が必要になることがあります。
- RANDOM分析には、対象曲・譜面の正規譜面データが必要です。
- 曲開始直後にCN（チャージノート）やHCN（ヘルチャージノート）が配置されている場合、ノーツイベントを正しく取得できず、正規譜面の記録やRANDOM解析に失敗する可能性があります。
- 曲名認識や分析がうまくいかない場合は、ランチャーの「詳細ログを表示（デバッグ用）」を有効にして状況を確認してください。
- 分析結果はゲーム画面からの検出に基づくため、常に正しい結果が得られることを保証するものではありません。

## 9. トラブルシューティング

**テンプレート初期設定が表示される／分析を開始できない**
必要なテンプレート画像が `templates/` に揃っていません。「⚙ 設定」→「テンプレート作成ウィザード」で不足分を登録してください。スクリーンショットは1920×1080のものを使用してください。

**スタートボタンが押せない／Tesseract OCRが利用不可**
Tesseract本体の場所、`jpn` / `eng` 言語データの有無を確認してください。標準以外の場所にインストールした場合はPATHを確認します。

**ゲーム映像が取得できない**
OBS側でゲーム画面が表示されているか、Spout送信が有効か、接続名が完全一致しているか確認してください。OBSとアプリを再起動して再確認します。

**曲名が認識されない／誤って認識される**
まず映像取得とTesseractの状態を確認してください。日本語の曲名では誤認識が発生しやすく、英語の曲名でも誤認識する場合があります。登録済みの曲名・譜面データは「⚙ 設定」→「曲名DB編集」で確認・修正できます。ただし、DBの修正はOCR自体の読み取り精度を改善するものではありません。

**曲開始は検出できるが、譜面の記録・RANDOM解析ができない**
「⚙ 設定」→「検出帯設定」でノーツが通過する位置を確認・調整してください。また、RANDOM解析には対象曲・譜面の正規譜面データが必要です。曲開始直後のCN・HCNを正しく取得できない場合など、検出帯の調整だけでは解決しないこともあります。

**EXEが起動しない／必要ファイルがないと表示される**
ZIPからフォルダ全体を展開し、`_internal` 等をEXEと同じ配布構成のまま置いてください。EXEだけを単独コピーしないでください。

## 10. 配布する方への注意

- `dist\RandomLaneAnalysis_OCR\` **フォルダ全体**をZIP化して配布します。
- **ゲーム画面由来のテンプレート画像（`templates/`）やそのバックアップ（`template_wizard_backup/`）は同梱しません。** 利用者がウィザードで作成します。
- 配布前に設定ファイル、曲名DB、履歴CSV等に個人用・検証用の情報が含まれていないか確認してください。
- 外部ソフトのインストーラーは同梱せず、各公式・開発元の配布ページへ案内する構成を推奨します。
- このREADMEは確認済みのEXE構成とSpoutプラグイン1.12.0に基づきます。**別PCでの新規導入テスト、およびOBSの具体的な送信設定手順の照合は未実施**です。
